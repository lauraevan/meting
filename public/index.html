Meting API

基于 Meting 的音乐 API，支持网易云、QQ 音乐、酷狗、百度、酷我。

请求

GET /api?server=netease&type=search&id=关键词
参数说明
servernetease / tencent / kugou / baidu / kuwo，默认 netease
typesearch / song / album / artist / playlist / url / lyric / pic
id搜索关键词或资源 ID（必填）
page, limit搜索分页，默认 1 / 30；artist 的 limit 默认 50
brurl 码率（kbps），默认 320
sizepic 尺寸，默认 300
format传 0 返回平台原始数据，默认返回标准化数据

示例

  • /api?server=netease&type=search&id=烟火里的尘埃&limit=5
  • /api?server=netease&type=song&id=35847388
  • /api?server=netease&type=lyric&id=35847388

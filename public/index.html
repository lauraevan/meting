Meting API

A music API powered by Meting. Supports NetEase Cloud Music, QQ Music (Tencent), Kugou, Baidu and Kuwo.

Request

GET /api?server=netease&type=search&id=keyword
ParameterDescription
servernetease / tencent / kugou / baidu / kuwo (default netease)
typesearch / song / album / artist / playlist / url / lyric / pic
idSearch keyword or resource ID (required)
page, limitSearch pagination, default 1 / 30; for artist, limit defaults to 50
brBitrate in kbps for url (default 320)
sizeImage size in pixels for pic (default 300)
formatSet to 0 to return the platform's raw data; normalized data is returned by default

Examples

  • /api?server=netease&type=search&id=hello&limit=5
  • /api?server=netease&type=song&id=35847388
  • /api?server=netease&type=lyric&id=35847388
